# LiteraturaApp

**LiteraturaApp** es una aplicación desarrollada como práctica para fortalecer conocimientos en backend. La aplicación permite gestionar información sobre libros y autores utilizando una combinación de APIs, persistencia de datos y buenas prácticas de programación.

## ¿Qué hace esta aplicación?
La función principal de LiteraturaApp es mostrar información sobre libros y autores obtenida desde una API externa. Esta información se almacena en una base de datos para permitir su consulta posterior. Además, la aplicación proporciona varias funcionalidades clave:

### Características principales:
1. **Buscar libros desde la API**:
   - Permite buscar información de un libro desde una API externa.
   - Si el libro no ha sido registrado previamente, se guarda en la base de datos.

2. **Listar libros guardados**:
   - Muestra una lista de todos los libros almacenados en la base de datos.

3. **Listar autores guardados**:
   - Muestra una lista de todos los autores almacenados en la base de datos.

4. **Listar autores vivos en un año específico**:
   - Permite al usuario introducir un año y listar los autores que estaban vivos en ese periodo.

5. **Listar libros según idioma**:
   - Muestra los libros almacenados en la base de datos según el idioma especificado por el usuario.

## Tecnologías utilizadas
La aplicación se desarrolló utilizando las siguientes tecnologías:

- **Java**: Lenguaje de programación principal para la lógica de la aplicación.
- **Spring Boot**: Framework para construir la arquitectura backend, incluyendo:
  - Desarrollo de controladores REST.
  - Gestión de dependencias y configuraciones.
- **PostgreSQL**: Sistema de base de datos utilizado para almacenar información de libros y autores.

## Objetivo de aprendizaje
Esta aplicación fue desarrollada con el objetivo de:

1. Reforzar conocimientos sobre desarrollo backend con **Java** y **Spring Boot**.
2. Practicar el consumo de APIs externas y el manejo de datos.
3. Implementar persistencia de datos utilizando **PostgreSQL**.
4. Adoptar y aplicar **buenas prácticas de programación**.
